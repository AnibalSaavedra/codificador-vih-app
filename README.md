
# 🧬 Codificador VIH - MINSAL

Este software permite generar automáticamente un código de identificación para exámenes de VIH de acuerdo con los lineamientos del Ministerio de Salud de Chile (MINSAL), ocultando la identidad del paciente y facilitando la trazabilidad segura.

## 🚀 Funcionalidades

- Ingreso de nombre completo, RUT y fecha de nacimiento.
- Generación automática del código VIH según norma.
- Exportación de los datos y código generado a un archivo PDF.
- Interfaz amigable vía aplicación web Streamlit.

## 📦 Cómo usar

1. Instalar dependencias:
    ```bash
    pip install streamlit fpdf
    ```

2. Ejecutar la app:
    ```bash
    streamlit run app.py
    ```

3. Completar el formulario y descargar el PDF generado.
